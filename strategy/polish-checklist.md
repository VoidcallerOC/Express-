# Polish and Differentiation Checklist

The finished site should pass every check below before launch.

- **Local personality:** The copy should sound like a Newington neighborhood business, not a generic pizza template.
- **Express identity:** The approved current name and logo should be consistent across header, metadata, footer, and social links.
- **Pizza + Scoops identity:** The combination should be visible if the owner confirms scoops as an active offering; do not bury or invent it.
- **Ordering speed:** A mobile visitor should reach the preferred order destination in one clear tap from the homepage.
- **Menu clarity:** Categories should be grouped for scanning, with no unexplained marketplace taxonomy.
- **Mobile UX:** Phone, directions, hours, menu, and order actions should be reachable without hunting.
- **Food imagery:** Use a small set of current, client-approved images with meaningful alt text.
- **Local SEO:** Canonical NAP, metadata, structured data, sitemap, and location copy must agree.
- **Trust:** Show accurate hours, address, phone, ordering expectations, and links to legitimate profiles.
- **Conversion:** Every page has one primary next step and the footer repeats critical actions.
- **Accessibility:** Keyboard, screen-reader, contrast, focus, motion, headings, and touch-target checks pass.
- **Performance:** Images are optimized, third-party scripts are limited, and layout shift is controlled.
- **No platform cosplay:** The site should not imitate a marketplace checkout or promise unsupported delivery features.
- **No brand confusion:** Best Pizza appears only if the approved transition strategy calls for it.
